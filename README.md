# 🌦️ Clima Agora

Uma aplicação web desenvolvida para consultar o clima atual e a previsão dos próximos dias de cidades brasileiras, com uma interface moderna, responsiva e intuitiva.

## ✨ Sobre o projeto

O **Clima Agora** nasceu como um projeto de estudos para praticar desenvolvimento web utilizando APIs externas, manipulação do DOM e versionamento com Git. Durante o desenvolvimento, novas funcionalidades foram sendo adicionadas para tornar a experiência mais próxima de um aplicativo real.

## 🚀 Funcionalidades

* 🔍 Busca do clima por nome da cidade;
* 📍 Consulta do clima utilizando a localização atual do usuário;
* 🌤️ Exibição do clima em tempo real;
* 📅 Previsão do tempo para os próximos 5 dias;
* ⌨️ Pesquisa utilizando a tecla Enter;
* 📱 Layout responsivo para dispositivos móveis;
* 🎨 Fundo dinâmico baseado nas condições climáticas e temperatura;
* 🕒 Histórico das últimas pesquisas utilizando Local Storage;
* 📌 Pesquisas recentes exibidas ao clicar na barra de busca;
* 🚀 Deploy automático utilizando Vercel.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (ES6+)
* Fetch API
* OpenWeather API
* Local Storage
* Git
* GitHub
* Vercel

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, foram praticados conceitos importantes, como:

* Consumo de APIs externas;
* Programação assíncrona com Async/Await;
* Manipulação do DOM;
* Tratamento de erros;
* Geolocalização do navegador;
* Armazenamento local com Local Storage;
* Responsividade para diferentes tamanhos de tela;
* Versionamento de código com Git;
* Publicação e deploy de aplicações web.
