# 🌦️ Clima Agora

Aplicação web desenvolvida para consultar o clima atual e a previsão dos próximos 5 dias de qualquer cidade do Brasil.

## 🚀 Funcionalidades

* 🔍 Busca por cidades brasileiras
* 📍 Consulta do clima pela localização atual
* 🌤️ Exibição do clima em tempo real
* 📅 Previsão para os próximos 5 dias
* ⌨️ Busca ao pressionar Enter
* 📱 Layout responsivo para celulares
* 🌐 Projeto publicado na internet com a Vercel

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* OpenWeather API
* Git
* GitHub
* Vercel

## 📚 O que aprendi com este projeto

Durante o desenvolvimento deste projeto, aprendi conceitos importantes como:

* Consumo de APIs utilizando Fetch API;
* Manipulação do DOM;
* Uso de Async/Await;
* Tratamento de erros;
* Responsividade para dispositivos móveis;
* Versionamento de código com Git;
* Hospedagem e deploy com GitHub e Vercel.
